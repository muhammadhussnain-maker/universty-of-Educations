# University of Education Faisalabad Campus — Real Photo Experience

This build removes the rendered/model campus gallery and uses the University's official Faisalabad conference-gallery image URLs for the photo presentation.

## Included
- Photo-first hero/overview and campus gallery
- Cinematic zoom, hover, parallax and responsive layout
- Faisalabad Campus history and 23-acre site detail from the official UE campus page
- Official Faisalabad departments and facilities links
- Fall 2026 university update cards
- Admissions, UMS, LMS, complaints, financial aid, journal, EIRB and other official-resource shortcuts
- Campus map and contact section

## Important
The official photo binaries are referenced from the University's live server because this build environment could not retrieve the UE image files as local binaries. No generated campus model is presented as an official photograph.
